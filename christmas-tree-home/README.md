# ほんもののクリスマスツリー — 3Dトップページ比較試作

4歳児向け3Dモバイルゲーム「ほんもののクリスマスツリー」の**トップページだけ**を、14の大きく異なる世界・作業場・光環境で比較するWebGL試作です。

本編の調査基準は、米国ノースカロライナ州 Asheville の **Biltmore Estate / Banquet Hall Christmas Tree**、特に公開情報が充実している2025年（130回目のクリスマス・シーズン）の設営です。35フィート級の生のFraser firを選定し、搬入経路を通し、大人数で起立・固定し、足場と長い手製の道具を用いて数百の灯り・装飾を仕上げる工程を、一次情報と現地報道から再構成しました。

> 現在の実装範囲はトップページのみです。計画、木の選定、搬入、起立、固定、枝起こし、配線、装飾、点灯、維持管理、撤収は、次回以降に本編として実装する前提です。

## 起動

ES Modulesを使用するため、ファイルを直接開かず、ローカルHTTPサーバーから起動します。

```bash
cd christmas-tree-home
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

Three.js本体はjsDelivr CDNから読み込むため、初回表示にはネット接続が必要です。

## 操作

- 左右スワイプ、左右矢印、画面下の番号で14案を切り替え
- 3D画面を少し指で動かすと、視点が小さく追従
- 「はじめる」で、本編第1工程につながる仮画面を表示
- 情報ボタンで試作範囲を表示
- 音ボタンで短い操作確認音を切り替え

4歳児が使うことを想定し、主要ボタンは大きなタッチ領域を持ち、スワイプ判定は短めです。iPhone/iPadの縦・横、安全領域、`prefers-reduced-motion` に対応します。

## 画像ではなくWebGL実ジオメトリ

木、幹、枝、針葉、スタンド、支線、電球、コード、飾り、床、壁、梁、窓、石、木箱、台車、足場、工具、人、雪、水面などをThree.jsのメッシュ／インスタンスで構成しています。生成画像や一枚背景で奥行きを偽装していません。

木は積み重ねた円錐ではなく、幹から異なる角度・長さで出る枝と針葉群で構成しています。枝密度、枝角度、飾りの位置には決定論的な不均一さを与え、完全な左右対称を避けています。

## 典型的なAI生成CGの癖を避ける

- 根拠のないネオン、発光縁、ブルーム、過剰な背景ぼけを使用しない
- 全面を均一なプラスチック光沢にしない
- 角を用途なく丸めない
- 汚れ・摩耗を左右対称な模様として付けない
- 支えのない巨大木、宙に浮く木箱、重量を無視した装飾を作らない
- 支線、重り、ボルト、水槽、足場、床養生、配線を必要な場所に置く
- 光源は窓、天窓、炉、暖炉、街灯、作業灯など、場の機能から決める
- 近景・中景・遠景を、遮蔽、輪郭、材質粗さ、光量差、フォグで分離する

## パフォーマンス方針

- 針葉・反復飾りは`InstancedMesh`を使用
- 端末の`devicePixelRatio`を上限付きで使用
- 案の切替時に前シーンのジオメトリ・材質・テクスチャを破棄
- 影を落とす光源とメッシュを限定
- ポストプロセスのブルームや被写界深度を不使用
- `prefers-reduced-motion`時は視差と切替動作を抑制

## 検証

- `node --check src/main.js`：ローダー構文確認
- runtime 6分割を連結して`node --check`：本体構文確認
- `node tests/static-check.mjs`：14案・builder・HTML ID・CSS・entry pointの静的確認
- ローカルHTTPサーバー：主要ファイルの200応答確認
- iPhone/iPad縦・横、安全領域、縮小モーション、タッチ入力：コード上の確認

実施結果と未確認事項は [`docs/VALIDATION_JA.md`](./docs/VALIDATION_JA.md) に記録しています。

## 調査上の制約

公開情報から確認できない事項は、事実として捏造していません。たとえば、2025年の正確なスタンド寸法、固定ボルト本数、ワイヤ径、電気回路、搬入経路の実測幅、装飾品ごとの寸法・重量、全作業員の役割表は非公開です。3D案で必要な寸法・構造は、公開された木の尺度、一般的な建築・施工・什器寸法、および安全に成立する構造から導いた**設計仮説**です。
