# トップページ14案 — 比較設計

## 1. 比較の目的

14案は、同じツリーへ色フィルターを掛けた比較ではない。次の軸を同時に変えている。

- 国・地域と気候
- 屋内／屋外／半屋外
- 家庭／商業／公共／工房／技術展示
- 朝／正午／夕方／夜／極夜
- 自然光／天窓／炉火／暖炉／街灯／作業灯
- 生木／小型生木／大型生木
- 完成／搬入／起立／製造／施工途中／構造解説
- 石／木／ガラス／鉄／畳／紙／雪／水など主材質
- 写実ドキュメンタリー／静物的写実／技術カットアウェイなど表現文法
- 近景・中景・遠景の役割
- UIの形・位置・書体・境界の作り方

共通なのは、画像背景に逃げず、木・建築・道具をWebGLの実ジオメトリとして置くことだけである。

# 2. 各案

## 01　Biltmore大広間 — 「大広間に木がやってきた」

### 世界

米国Asheville、歴史的な石造Banquet Hallを下敷きにした写実的な設営朝。

### 時間・光

朝。高窓からの斜光と、シャンデリアの弱い暖色。ツリー電球は点いているが、昼光に負けず材質を補助する程度。

### 近景

開いた木箱、床養生、長い装飾竿、台車。板厚、角材、擦れ、床への接地が読める。

### 中景

35フィート級のFraser fir、スタンド、重り、支線、足場、作業員。木は円錐の積み重ねではなく、幹から枝が出る。

### 遠景

石壁、高窓、梁、オルガンロフト。木の巨大さを建築との相対尺度で示す。

### 主材質

針葉樹、樹皮、石灰岩、オーク、鉄、麻布、ガラス、真鍮。

### リアリティ

14案中もっとも「現場写真」に近い。完成だけでなく、道具と支持構造を残す。

### UI

歴史的施設の案内札を想起させる、半透明の左パネルと明朝系タイトル。角を過度に丸めない。

### 狙い

ユーザーの写実・工程・重量感への好みと最も直接に合う本命。

## 02　ニューヨーク都市広場 — 「青い街に、金の灯り」

### 世界

巨大な都市広場。高層建築、スケートリンク、人流、安全柵を含む公共スケール。

### 時間・光

ブルーアワー。空と建物は青灰、電球と街灯は現実的な暖色。ネオン縁取りは使わない。

### 近景

安全柵、濡れ気味の舗装、人々の足元。

### 中景

都市スケールの大型木と群衆。人を点景にせず、木の尺度を読む基準にする。

### 遠景

直方体の高層建築と窓灯、スケートリンク。

### 主材質

花崗岩、鋼、氷、ガラス、針葉樹。

### リアリティ

建築写真・都市ドキュメンタリー寄り。豪華さより、公共空間へ巨大物を置く難しさを見せる。

### UI

上端が切れた幾何学パネル、細い都市案内の文字、円形ボタン。01とはレイアウト文法が異なる。

### UI

## 05　沖縄の海辺テラス — 「南の島のクリスマス」

### 時間・光

### リアリティ

### UI

# 4. ユーザー嗜好からの採用予測

## 本命

### 01　Biltmore大広間

理由：実在事例への直接性、巨大物の重量、歴史建築、近景の道具、中景の木、遠景の会場が全て揃う。写実性と物語性のバランスが最も高い。

### 14　技術カットアウェイ

理由：支持構造・接地・水・電気・足場を隠さない。AI生成CGにありがちな「なぜ立っているか分からない美しい物体」を正面から避ける。

## 対抗

### 12　エディンバラ駅

理由：濡れた石、鉄、ガラス、列車、人流、台車が、材質・奥行き・物流を強く見せる。

### 05　沖縄テラス

理由：生活圏との接続があり、雪景色の借用ではなく、風・湿度・塩害・防滴という固有条件から画面を設計している。

## 穴

### 10　ラップランド起立

理由：完成の華やかさを捨て、木を立てる重さと協働だけを主役にする。ゲーム本編の核が最も明瞭。

### 08　チェコのガラス工房

理由：装飾工程を「掛ける」から「作る」へ遡る。炉火、薄ガラス、鉄道具という材質コントラストが強い。

## 大穴

### 06　ヘルシンキの居間

理由：巨大・豪華を捨て、4歳児が実際に家庭で触れ得る高さへ戻す。ゲーム本編の理解しやすさでは大型会場を上回る可能性がある。
