# 05 花の小道 — 完成ピーク10案

4歳児向け3Dモバイルゲーム「おはなのウェディング」で採用されたトップページ案05「花の小道」から続く、**搬入と現地設営が終わった瞬間の完成ピーク比較**です。

背景画像や生成画像を置いた比較ではありません。花弁、花房、茎、葉、枝、器、水面、通路、椅子、アーチ、梁、重り、灯具、台車、脚立、道具箱などをThree.jsのWebGLジオメトリとして組み立てます。

## 起動

リポジトリのルートでHTTPサーバーを起動します。

```bash
python3 -m http.server 4173
```

次を開きます。

```text
http://localhost:4173/garden-aisle-peak/
```

Three.jsをCDNから読み込むため、初回表示には通信が必要です。ファイルを直接ダブルクリックせず、HTTP経由で開いてください。

## 操作

- 画面を左右へ短くスワイプ、左右矢印、下部の番号で10案を切り替え
- 画面上の目のボタンで「ゲスト目線」と「装花スタッフ目線」を切り替え
- 3D画面上で指を動かすと、視点がごく小さく追従して近景・中景・遠景の視差を示す
- 音は初期状態でオフ。スピーカーボタンで短い確認音だけを有効化
- 左上から元のトップページ案05へ戻る

## 現実性の方針

- 通路中央は塞がず、花は椅子列と通路の境界へ置く
- 花門、藤棚、白樺枝、吊り花には支持構造を持たせる
- 大型器、重り、台車、脚立、消火器、給水具を「華やかさの裏側」として装花スタッフ視点に残す
- 花の高さ、茎長、方向、密度を完全左右対称にしない
- 均一なプラスチック光沢、発光縁、根拠のないネオン、被写界深度による過剰な背景ぼけを使わない
- 花弁と葉はInstancedMeshへまとめ、10案の比較試作として描画負荷を抑える

## 検証

```bash
node garden-aisle-peak/tests/validate.mjs
```

この検証は、10案の重複・必須データ・縦横CSS・短いスワイプ・トップページ05との接続・決定論的配置を確認し、Three.js互換スタブ上で全10シーンの構築関数を最後まで実行します。

実機での最終確認項目は、iPhone/iPad Safariにおける色、影、メモリ、発熱、フレームレート、縦横回転後の構図です。
