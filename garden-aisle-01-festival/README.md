# 01「花の小道」— 会場ぜんぶを祝祭にする12案

採用済みトップページ **05「花の小道」** の完成ピーク案のうち、高評価だった旧ピーク01を土台にし、花だけでなく、椅子、地面、建築、木々、照明、参列者、演奏者、楽器、什器、意外な祝祭装置まで変更した比較実装です。

比較番号は **A1〜A12** です。すべて旧ピーク01の派生であり、絶対的不採用となった旧02「白薔薇」と旧10「蘭枝」は含みません。白一色、白花中心、蘭枝中心の配色・構成も使用していません。

## 起動

外部ライブラリや画像素材を読み込まないため、ローカルHTTPサーバーだけで動作します。

```bash
cd garden-aisle-01-festival
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 操作

- 左右スワイプ、左右矢印、画面下のA1〜A12で比較
- 目のボタンで「ゲストの目線」と「装飾のそば」を切替
- 「みんなで拍手！」で、参列者、演奏者、泡、色紙などの祝祭動作を再生
- 音ボタンで短い完成チャイムを任意に有効化
- `?v=7` のようなクエリで初期案を指定

4歳児の短い指運動でも切り替わるよう、横方向約40pxのスワイプを成立距離とし、主要操作には大きいタッチ領域を持たせています。

## 実装

- HTML + CSS + JavaScript
- ライブラリ非依存のRaw WebGL
- 背景画像、生成画像、写真テクスチャは不使用
- 建物、椅子、人物、楽器、樹木、花、舗装、アーチ、照明器具、屋台、噴水等をメッシュで構築
- 近景・中景・遠景を、遮蔽、寸法差、フォグ、光量差、視差で分離
- 不透明物と半透明物を分けて描画
- 端末幅に応じたカメラ、UI、安全領域、縦横画面対応
- `prefers-reduced-motion` 対応
- 通常時は約30fpsを上限にし、端末のDPRを制限
