# 輪島塗を、つくろう。— Top Page Study

4歳児向け3Dモバイルゲーム「輪島塗を、つくろう。」のトップページ比較実装です。  
色替えではなく、光源、カメラ、写実度、材質、空間、UI構成を変えた**15の独立案**を収録しています。

## 起動

相対パスを安定して読み込むため、ローカルHTTPサーバーで開きます。

```bash
python3 -m http.server 8000
```

```text
http://localhost:8000/?v=01
```

`01` を `15` まで変えると各案へ直接移動できます。

## 操作

- 画面をなぞる: 工房を見回す
- 画面を軽くタップ: 工程予告を再生
- 「つくりはじめる」: 6.8秒の工程予告
- 左右ボタン／左右キー: 案を切り替える
- 「案をくらべる」／`G`: 15案一覧
- `Esc`: 一覧を閉じる

## 技術

- WebGL 2
- 外部ライブラリなし
- 外部画像・フォントなし
- 椀、机、棚、道具、塗師風呂、分解層を実ジオメトリで生成
- 木、布、地の粉、紙、漆、鉄、金、水、石をプロシージャル材質で描き分け
- 透視／正投影、最大4灯、距離フォグ、微粒子
- iPhone / iPadの縦横、安全領域、Retina解像度を考慮
- 主要ボタンは4歳児向けの大型タッチ領域

## 調査と本編設計

- [輪島塗の製造工程調査](docs/wajima-process-research.md)
- [4歳児向け本編計画](docs/game-design-plan.md)

文化庁の32状態を工程管理の背骨とし、公開される細工程を内部ログへ割り当てる方針です。子どもが直接触る工程は14章へ圧縮しますが、乾燥、硬化、研ぎ、再塗り、清掃、工房間の受け渡しは自動再生として残します。

## 今回の範囲

トップページと15案比較UIのみです。「つくりはじめる」は本編へ遷移せず、木地から加飾までの短い予告を再生します。次の実装では、工程データ、基準煮物椀、材質試験室、ろくろ・布着せ・地付け・水研ぎ・上塗の順に接続します。
