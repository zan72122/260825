# 百二十四の層 — 輪島塗を、つくろう。

4歳児向けの3Dモバイルゲームです。採用されたトップページ案08「百二十四の層」を核に、**木を選ぶところから、ろくろ、刻苧、布着せ、輪島地の粉による三層の下地、水研ぎ、中塗、上塗、塗師風呂、呂色、沈金／蒔絵、検品まで**を、15章・41操作で一続きに実装しています。

一枚絵を背景に置いた疑似3Dではありません。椀の内外面、口縁、高台、各層、道具、棚、作業台、塗師風呂、木箱などをWebGL 2の実ジオメトリとして描画します。

> 実装ブランチ: `wajima-nuri-top-pages`  
> 現在の状態: トップページ試作ではなく、開始から完成・工程帳・保存・再開まで通して遊べる本編

## 起動

外部ライブラリ、外部画像、外部フォントは使っていません。ES Modulesを使うため、ファイルを直接開かず、ローカルHTTPサーバーから起動します。

```bash
python3 -m http.server 4173
```

ブラウザで次を開きます。

```text
http://localhost:4173
```

または、次でも起動できます。

```bash
npm run serve
```

初回読み込み後はService Workerがゲーム本体をキャッシュします。HTTPSまたはlocalhost上では、ホーム画面へ追加した後のオフライン起動に対応します。

## ゲームの構造

| 章 | 主な体験 | 子どもの操作 |
|---:|---|---|
| 01 | 木を選び、椀木取り・燻煙・乾燥を見る | 大きな木をタップ |
| 02 | 荒挽き・外挽き・内挽き・底挽き | 横へ何度もなぞる |
| 03 | 亀裂を見つけ、刻苧で直す | タップ、線なぞり、へら送り |
| 04 | 木地磨きと木地固め | 円運動、上から下へ塗る |
| 05 | 布着せ | 大きく運ぶ、中央から外へ押す |
| 06 | 布削りと惣身 | 口縁をなぞる、段差を埋める |
| 07 | 生漆・米糊・地の粉を混ぜる | 注ぐ、くるくる混ぜる |
| 08 | 一辺地・二辺地・三辺地を重ねる | へらを横へ押し送る |
| 09 | 地研ぎと地固め | 水を加える、広く往復する |
| 10 | 中塗・中塗研ぎ・錆さらい・小中塗 | 長く塗る、欠陥を探して埋める |
| 11 | 上塗 | 清掃、内外を一息で長く塗る |
| 12 | 塗師風呂 | 棚へ運ぶ、湿度を合わせる、回す |
| 13 | 呂色 | 炭研ぎ、摺り漆、艶上げ |
| 14 | 沈金または蒔絵 | 方法を選ぶ、文様をなぞる、金を入れる |
| 15 | 検品と箱入れ | 一周回す、三点検査、木箱へ運ぶ |

各章の末尾には、子どもへ毎回同じ操作を要求するとテンポを崩す工程を**自動工程映像**として入れています。乾燥、硬化、軽い研ぎ、再塗装、清掃、測定、工房内の受け渡しを消さず、3段階の説明と3Dタイムラプスでつなぎます。

## A・B・Cの実装

### A. 現実を忠実に再現

- 閉じた外面・内面、口縁、高台を別の実ジオメトリで構成
- 木、麻布、粗・中・細の地の粉、生漆、硬化漆、水、研ぎ泥、鉄、石、紙、金を別材質で描画
- 漆と金は発光させず、光源を受けて反射する材質として表現
- 「塗る→待つ→研ぐ→再び塗る」の反復を保持
- 塗師風呂を熱風乾燥機にせず、湿度のある陰室として実装
- 沈金は刃物、蒔絵は筆を使い、金の前工程を分ける
- 工具・器・棚・作業台に接地と実用上の厚みを持たせる

### B. 4歳児に読める誇張

- 断面表示中だけ、木・布・三種の下地・中塗・上塗・金を読みやすく離す
- 粗・中・細の粒径差を、説明場面では実物より明瞭にする
- 正しい場所は、発光輪郭ではなく、道具の予備動作・薄い手本軌跡・短い音で示す
- 研ぎは「高い場所から曇る」、艶上げは「反射の帯がつながる」で結果を示す
- 誤方向でも進捗を失わず、失敗画面を出さない

### C. タッチで作った感覚を残す

- 一本指のタップ、短いスライド、連続スワイプを基本操作にする
- 指の移動を約1.45倍へ増幅
- 見た目より広い掴み・置き・経路判定
- 線なぞりは弱い磁気吸着をかけるが、自動完成にはしない
- 子どもの指の軌跡を、刷毛目、研ぎ跡、粉、削り屑として3D空間へ残す
- 約2.4秒止まると短い手本が現れる

## 32状態の工程帳

ゲームの裏側では、文化財工程見本を参照した32状態を保持しています。子どもは15章だけを意識して遊べますが、工程帳を開くと、原木から検品まで何を見たか確認できます。

「124工程」は工房、器種、仕上げ、工程の数え方によって細分が変わるため、固定された架空の124項目を捏造していません。ゲームでは32状態を工程管理の背骨とし、その間にある乾燥・硬化・反復・清掃・測定を自動工程へ割り当てています。

詳しい対応は [`docs/PROCESS_COVERAGE_JA.md`](docs/PROCESS_COVERAGE_JA.md) を参照してください。

## 操作

- 指でなぞる：各工程の主操作
- 2.4秒待つ：その工程の手本を表示
- 右上「帳」：32状態の工程帳
- 工程帳「断面をみる」：採用案08の全層表示
- ホーム：自動保存して戻る
- 音符：音のオン／オフ
- 完成後「うつわを まわす」：斜光の反射と金の見え方を確認

開発・確認用キーもあります。

- `K`：現在の操作を完了
- `N`：次章へ
- `B`：工程帳
- `H`：ホーム
- `Shift + ← / →`：到達可能な章を移動
- `?chapter=7&step=2`：指定章・手順を直接表示
- `?complete=1`：完成画面を表示

## 保存

`localStorage`へ次を保存します。

- 現在の章と手順
- 完了済みの32状態
- 選択した木材
- 沈金／蒔絵の選択
- 音設定
- 完成状態

再読み込み後は「つづきから」で再開できます。

## 現時点の限界

- 実際の4歳児によるユーザビリティ試験は未実施です。判定値は研究知見と幼児向け設計から置いた初期値で、実機観察後に調整が必要です。
- iPhone／iPad実機Safariの全機種で最終フレームレートを測った段階ではありません。
- 椀と工具は、工程理解とタッチ体験のためのプロシージャル3Dです。文化財の三次元計測データやフォトグラメトリそのものではありません。
- 呂色仕上げを本編の主経路にしています。花塗など別仕上げは工程帳上の解説対象で、独立した遊択経路にはしていません。
- 天然漆には皮膚障害の危険があります。ゲームは実作業を幼児へ勧めるものではありません。
