# おはなのウェディング — 3Dトップページ比較試作

4歳児向け3Dモバイルゲーム「おはなのウェディング」の**トップページだけ**を、14の大きく異なるデザイン仮説で比較できるWebGL試作です。

調査基準は、米国ペンシルベニア州Doylestownの **Aldie Mansion** で実施され、**Hatfield Florist** が装花を担当した公開事例です。実例で確認できる花材・設置場所・相談・現地確認・式後の再配置と、一般のフラワーデザイン実務資料から補う工程・構造を分けて扱っています。

> 現在の実装範囲はトップページのみです。水揚げ、制作、搬入、設営、再配置、撤去などのゲーム本編は、次回以降に追加する前提です。

## すぐに動かす

ES Modulesを使用するため、ファイルを直接開かずローカルHTTPサーバーから起動します。

```bash
cd wedding-flower-home
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

Three.js本体は jsDelivr CDN から読み込みます。初回表示にはネット接続が必要です。

## 操作

- 左右スワイプ、左右矢印、画面下の番号で14案を切り替え
- 3D画面を指で少し動かすと、視点が小さく追従
- 「はじめる」で、本編第1工程へつながる仮遷移を表示
- 情報ボタンで、試作の範囲と縮尺上の注意を表示
- 音ボタンで、短い操作確認音を切り替え

スワイプ判定は小児向けに短めに設定し、主要ボタンはiPhone/iPadの縦・横画面で大きなタッチ領域を保ちます。`prefers-reduced-motion` にも対応します。

## 実装方針

### 画像ではなくWebGL実ジオメトリ

花、茎、葉、器、テーブル、椅子、アーチ、重り、金網、壁、床、噴水、窓、搬入車両などをThree.jsのメッシュとして構成しています。背景一枚絵や生成画像を置いて奥行きを偽装していません。

### AI生成CGにありがちな癖を避ける

- 全面が均一に光るプラスチック材質を使用しない
- 根拠のないネオン縁取り、ブルーム、過剰な被写界深度を使用しない
- 汚れや摩耗を左右対称の装飾として付けない
- 支えのない花、接地しない器、重量を無視した大型装花を作らない
- 構造案では、ベースプレート、重り、輪、網、結束、水源を露出
- 花材の配置は完全左右対称にせず、茎長・向き・密度に制御されたばらつきを持たせる

### 奥行き

各案で近景・中景・遠景を、輪郭、遮蔽、材質粗さ、光量差、フォグで分離しています。端末を傾ける必要はなく、少量の指移動だけで視差が読めます。

## 検証

- `node --check src/main.js`：構文確認
- ローカルHTTPサーバー：`200 OK`
- 14案すべてのシーン構築関数：スタブ環境で例外なく完走
- CSS波括弧整合：確認済み
- 縦・横、安全領域、縮小モーション、タッチ入力：コード上の確認済み

この実行環境ではheadless ChromiumがEGLを初期化できなかったため、GPUレンダリング後のスクリーンショット比較までは完了していません。実機Safariでの最終的な色、影、フレームレートの確認は、次工程の必須項目です。

## 現時点の制約

- Three.jsをCDNから読むため完全オフラインでは動作しません。
- トップページ比較用のため、椅子などの反復物は本編向けの完全なLOD・インスタンシング最適化前です。
- Aldie Mansionの実測図や、当該結婚式のアーチ内部構造・正確な花材本数は公開されていません。寸法や内部機構は、公開写真、一般的な什器寸法、別の実務資料を基にした設計仮説です。
- 「はじめる」後はプレースホルダーです。ゲーム本編は未実装です。
