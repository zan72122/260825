# 輪島塗（石川県）製造工程調査

調査日: 2026-08-25  
ゲーム化の基準製品: **蓋付き煮物椀**（文化庁の工程見本に合わせる）

## 1. 結論

輪島塗は「木の器に漆を何度も塗る」だけではない。構造上の核は、次の連鎖にある。

1. 用途に合う木地を作り、長期間乾燥させる。
2. 亀裂や接合部を刻苧で補修する。
3. 木地へ生漆を含浸させ、弱い箇所へ麻布・寒冷紗を貼る。
4. 輪島地の粉を使う下地を、粗い一辺地から細かい三辺地へ重ねる。
5. 各層を硬化させ、研ぎ、正しい形へ戻す。
6. 中塗・小中塗・上塗を行い、湿潤した塗師風呂で硬化させる。
7. 花塗または呂色で最終面を作る。
8. 必要に応じ沈金または蒔絵を施す。
9. 検品、養生、梱包を経て使い手へ渡り、使用と修理が「+1」として続く。

輪島漆器商工業協同組合は「124にも及ぶ工程」、THE WAJIMA は「約124+1」と説明している。ただし、公開資料からは、すべての製品・工房に一字一句共通する「公式124項目表」は確認できない。工程数は、椀・曲物・指物・朴木地の違い、花塗か呂色か、沈金か蒔絵か、反復回数、工房内の作業分割で変わる。

本ゲームでは、文化庁所蔵「輪島塗煮物椀制作工程見本」の**原材料2点＋工程見本30点＝32状態**を必須の背骨とし、協同組合が公開する細工程を各状態の内部ログへ割り当てる。これなら、子ども向けに操作数を圧縮しても、工程そのものは消えない。

## 2. 伝統的工芸品として外せない条件

伝産法に基づく輪島塗の要件として公開されている内容を、ゲーム内の「変更禁止事項」とする。

- 木地に生漆を塗った後、着せ物漆を塗った麻布または寒冷紗で布着せする。
- 生漆、米糊、輪島地の粉を混ぜたものを塗り、研ぐことを反復する。
- 上塗は精製漆を使い、花塗または呂色塗とする。
- 加飾する場合は沈金または蒔絵とする。
- 挽き物は、ろくろ台とろくろ鉋で成形する。
- 板物・曲物は刻苧漆を用いて成形する。
- 漆は天然漆。
- 木地はヒバ、ケヤキ、カツラ、ホオノキ、または同等材。
- 製造地域は石川県輪島市。

## 3. 分業

輪島塗を「一人の職人が一つの部屋で全部作る」と描かない。

| 職能 | 主な役割 |
|---|---|
| 椀木地師 | ろくろで椀・鉢・茶托などを挽く |
| 曲物木地師 | 薄板を曲げ、丸盆・茶櫃などを作る |
| 指物木地師 | 板を精密に組み、重箱・膳などを作る |
| 朴木地師 | 鑿・小刀・鉋で曲面的な木地を彫り出す |
| 塗師屋・塗師 | 受注、仕様調整、木地の手配、下地、中塗、上塗、品質管理 |
| 呂色師 | 上塗面の水研ぎ、摺り漆、艶上げ |
| 沈金師 | 漆面を彫り、溝へ漆と金を定着 |
| 蒔絵師 | 漆で文様を描き、金銀粉を蒔き、固着・研磨 |

ゲームでは章間に「椀が次の工房へ渡る」短い移動を入れ、分業を工程の地理として見せる。

## 4. 原材料

### 4.1 木地

| 木地 | 主な製品 | 製法 |
|---|---|---|
| 椀木地 | 椀、鉢、茶托、丸盆 | 木塊をろくろで回し、外・内・底を鉋で挽く |
| 曲物木地 | 丸盆、茶櫃、飯櫃 | 薄板を水で柔らかくし、型へ曲げ、縁と底を接着 |
| 指物木地 | 重箱、硯箱、膳 | 板を削り、木釘や刻苧漆で精密に組む |
| 朴木地 | 花器、盛器、脚、彫刻的形 | 図面から木取りし、鑿・小刀・曲面鉋で彫る |

### 4.2 漆

採取した漆液は、用途に合わせて精製される。

1. 原液を撹拌し、屑綿へ不純物を吸着させる。
2. 遠心分離等で粗濾しし、生漆を得る。
3. 加熱せず撹拌する「なやし」で粘度・光沢・作業性を調整する。
4. 加熱撹拌する「くろめ」で水分を減らし、透漆などへ調整する。
5. 必要に応じ黒色化し、黒漆を作る。
6. 吉野紙等で最終濾過する。

### 4.3 下地・補強材料

- **輪島地の粉**: 珪藻土を焼成・粉砕した下地材。粗・中・細を使い分ける。
- **米糊**: 生漆と練り、接着性・作業性を持たせる。
- **刻苧**: 生漆、木粉、米糊等を練った充填・接着材。
- **惣身粉**: 木粉を煎って炭化させた粉。木地と布の段差を埋める惣身漆へ使う。
- **麻布・寒冷紗**: 口縁、底、接合部などを補強する。上級品では総布着せもある。
- **砥石・研ぎ炭・砥の粉**: 各層の平滑化と最終研磨に使う。

## 5. 製造工程

### 5.1 企画・寸法・意匠

用途、寸法、口縁厚、胴の曲率、高台、蓋の合口、色、加飾を決める。丸物以外では図面や型板が重要になる。

### 5.2 椀木地づくり

協同組合の公開工程に沿う代表順序。

1. よく枯らした原木を製品寸法に合わせて輪切りにする。
2. 完成寸法より大きめに木取りする。
3. 外側・内側を荒い椀形へ削る。
4. 荒型を小屋の屋根裏に並べ、木屑等の煙で約半年、燻煙乾燥する。
5. 倉庫でさらに数か月〜1年ほど自然乾燥し、狂いを落ち着かせる。公開資料の目安は含水率14〜15%。
6. ろくろへ固定し、仕上がりより一回り大きく荒挽きする。
7. 外挽きで高さと外形を定規に合わせる。
8. 内挽きで内見棒を使い、深さと肉厚を確認する。
9. 底挽きで高台を仕上げる。
10. 蓋付きでは身と蓋の合口を合わせる。

### 5.3 木地検査・補修・固め

1. **切彫り**: 亀裂、接合部、補強箇所を小刀で浅く彫る。
2. **刻苧**: 刻苧を詰めて平らにする。深い傷は反復する。
3. **木地磨き**: 口縁・角・全面を磨き、次の漆が食いつく面にする。
4. **木地固め**: 生漆を薄く塗って拭き込み、木地へ浸透させる。
5. **木地拵え**: 歪み、口縁、合口、細部形状を再点検・調整する。

### 5.4 布着せ・布削り・惣身

1. 着せ物漆を薄く均す。
2. 壊れやすい口縁、底、接合部、または全面へ麻布・寒冷紗を貼る。
3. 中央から外へ指やヘラで押さえ、空気を逃がして密着させる。
4. 湿潤環境で硬化させる。
5. 布の重なりや布目の高低を小刀で削る。
6. 木地と布の段差へ惣身漆をヘラ付けする。
7. 硬化後、砥石で平らに研ぐ。

### 5.5 輪島地の粉による本堅地

原理は「粗い粒で骨格を作り、順に細かくして表面を閉じる」。

1. **一辺地付け**: 粗い地の粉を含む下地漆を、面ごとにヘラで付ける。口縁には地縁引きを行う。
2. **一辺地の空研ぎ**: 荒砥石で高い箇所を落とす。
3. **二辺地付け**: 一辺地より細かい粉の下地を付ける。
4. **二辺地研ぎ**: 硬化後に空研ぎする。
5. **三辺地付け**: さらに細かい粉の下地を付ける。
6. **地研ぎ**: 水と砥石で研ぎ、面、角、曲率を正しい形へ戻す。
7. **地固め**: 生漆を薄く含浸させ、下地を締める。

重要なのは、塗るたびに器が単純に太るのではなく、**塗って高低を作り、研いで設計形へ戻す**ことである。

### 5.6 中塗・小中塗・精密研ぎ

1. 中塗漆を薄く均一に塗る。
2. 埃を避け、湿度を保つ塗師風呂へ入れ、少なくとも一昼夜ほど硬化させる。公開資料の基準例は20℃・80%。
3. 錆さらいで突起を削り、凹みへ錆漆を埋める。
4. 青砥石や研ぎ炭で水研ぎする。
5. 小中塗を行い、再び塗師風呂で硬化させる。
6. 小中研ぎを行う。
7. 必要に応じ小中塗を反復する。
8. 拭き上げで微細な研ぎと清拭を行う。以後は手脂を付けない。

### 5.7 上塗

1. 塗師蔵・隔離空間を清掃し、埃を抑える。
2. 鳥羽根や刷毛で微細な埃を除く。
3. 毛の長い薄形の上塗刷毛で、内面と外面などを分け、適度な厚さへ塗る。
4. 付着した「ふし」を細い棒で除く。
5. 塗師風呂へ納める。
6. 漆の垂れと偏りを抑えるため、一定時間ゆっくり回転させる場合がある。

漆は「熱風で乾燥」させるのではなく、湿り気のある環境で酸化重合・硬化させる。ゲーム内の炉火は照明・暖房・生活環境として扱い、硬化装置にはしない。

### 5.8 花塗

上塗した塗り肌を研磨せず、最終面とする。上塗時の均一さ、埃管理、液垂れ防止がそのまま品質になる。

### 5.9 呂色塗

代表順序は次の通り。

1. 呂色研ぎ: 上塗面を研ぎ炭で平らに水研ぎする。
2. 胴擦り: 油で練った砥の粉を布へ付けて磨く。
3. 拭き上げ: 油分と不純物を除く。
4. 摺り漆: 上質な生漆を極薄く擦り込み、余分を和紙で拭き、硬化させる。
5. 一回目艶上げ。
6. 二回目摺り漆。
7. 二回目艶上げ。
8. 化粧摺り。
9. 化粧艶上げ。

反復回数や材料は工房・仕上げで変わる。

### 5.10 沈金

1. 和紙へ下絵を描く。
2. 置目で文様を転写する。
3. 沈金ノミで線・点・面を彫る。
4. 彫り溝へ透漆を摺り込む。
5. 平面側の余分な漆を拭き取る。
6. 金箔を真綿で叩き込む、または金粉を摺り込む。
7. 湿気を与え、溝内の漆へ定着させる。
8. 文様外の余分な箔・粉を拭き取る。
9. 十分に硬化させる。

ゲームでは黄色い線テクスチャにせず、溝と金を別の実ジオメトリまたは深度変位として持たせる。

### 5.11 蒔絵

1. 薄い和紙へ下絵を描く。
2. 置目で器へ転写する。
3. 絵漆で輪郭を描き、必要な面を塗る。
4. 半乾きのタイミングで、粉筒を軽く叩きながら金銀粉を蒔く。
5. 毛棒で外から内へ粉を寄せ、漆のある場所へ定着させる。
6. 硬化後、余分な粉を除く。
7. 摺り漆を行い、硬化を挟んで反復し、粉を固着させる。
8. 微細粉等で磨き上げる。

平蒔絵、高蒔絵、研出蒔絵では、盛り上げ、覆い、研ぎ出しの工程が異なるため、本編では上級分岐にする。

### 5.12 検品・養生・使用・修理

- 艶、刷毛むら、ふし、液垂れ、色差、研ぎ破り、合口、歪み、がたつき、口縁厚、接地を確認する。
- 必要に応じ磨き、局所補修、再塗りを行う。
- 十分に硬化・養生してから梱包する。
- 使用、洗浄、乾燥、経年変化、修理、次世代への継承が「+1」になる。

## 7. 時間スケール

THE WAJIMA の一般向け目安では、木地作り「5年以上＋1〜3か月」、下地3〜6か月、中塗・中研ぎ1〜2か月、拭き上げ・上塗1〜2か月、装飾2〜4週間、最終仕上げ1か月、検品1〜2週間とされる。これは全製品へ適用する厳密な標準時間ではなく、長い乾燥・硬化・反復を伝える目安として使う。

ゲームでは現実時間を短縮するが、待ち時間を消さない。燻煙乾燥、自然乾燥、塗師風呂、回転、職人間の受け渡しを短い自動再生で示す。

## 8. 3D化の基準

- 文化庁の完成煮物椀例は径14.1 cm、高さ9.0 cm。基準椀はこの比率を使う。
- 外側だけの殻ではなく、内面、口縁、高台、蓋の合口を持つ。
- 木地、布、粗・中・細の下地、乾いた漆、濡れた漆、硬化漆、金、鉄、石、紙を別材質として扱う。
- 接地影は高台の環状接触に対応させる。
- 金は黄色く発光させず、金属反射として光源へ応答させる。
- 汚れは作業由来に限定する。刷毛置きの漆跡、砥石周辺の研ぎ泥、手で触る木部の摩耗など、位置に理由を持たせる。
- 遠景は過剰にぼかさず、照度差、コントラスト差、空気遠近、遮蔽で分離する。

## 9. 調査上の限界

- 「124工程」の全項目を、現行のすべての工房・製品に共通する一つの公式番号表として公開した資料は確認できなかった。
- 公開ページの一部には古い文字コード由来の文字化けがある。
- 漆の配合、反復回数、硬化条件、研磨材は職人、季節、製品、仕上げで変わる。
- したがって本編では、**32状態を必須、細工程を内部ログ、製品別に分岐**という三層構造を採用する。
