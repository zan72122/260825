# 4歳児向け3Dモバイルゲーム計画

## 1. 仮題

**おはなのウェディング — きょうは会場のお花屋さん**

## 2. 最重要コンセプト

プレイヤーが「花の絵を選んで置いた」のではなく、**朝、花店に届いた切花を整え、水を吸わせ、構造を組み、運び、本物の会場で完成させ、式後に披露宴へ移した**と感じること。

4歳児向けであっても、仕事の原因と結果は消さない。

- 水へ入れたから花が持ち直す
- 葉を水中から除いたから水が濁りにくい
- 重りを置いたからアーチが倒れない
- 低く作ったから卓上越しに向かいの顔が見える
- 小分けに作ったから台車で運び、式後に移せる

この因果を、説明文ではなく触った結果で理解させる。

## 3. A・B・Cの定義

| 要件 | 本ゲームでの意味 | 守るもの |
|---|---|---|
| **A 現実を忠実に再現** | 花は水、重力、器、構造、搬入、時間、会場規則に従う | 寸法、厚み、荷重、接地、支持、水位、動線、材質、工程順 |
| **B 4歳が直感的に理解** | 正解の因果を大きく、遅く、読みやすく見せる | 大きな把持部、短い工程、色分け、幽霊形状、手本動作、失敗しない補助 |
| **C 製造感のあるタッチ体験** | 指の動きが茎、刃物、水、台車、結束、器の動きへ連続的に伝わる | ドラッグ、なぞる、押す、すくう、注ぐ、差す、巻く、運ぶ、整える |

### バランス原則

- **BのためにAの因果を消さない。** 例：花が自動で浮いてアーチへ付くのではなく、指で差し込み、広い補助範囲が正しい金網の穴へ導く。
- **Cのために危険・精密操作を要求しない。** 例：実際の花鋏を模した道具は出すが、刃へ指を近づける操作ではなく、太い安全ハンドルを一回押す。
- **Aのために退屈な反復を増やさない。** 例：200本すべてを操作させず、代表的な5〜8本を触ると、残りは同じ原理でスタッフが自動作業する。

## 4. プレイヤー像

- 4歳、文字を読まなくても遊べる
- 片手・人差し指中心
- 長押し、ピンチ、二本指回転、細かな角度合わせを前提にしない
- 1工程への集中時間は短い
- 「水が増える」「花が起きる」「重い物が動く」「形がつながる」など、目に見える変化を好む
- 間違いを罰せず、やり直しの原因を目で理解できるようにする

## 5. 世界設定と一日の流れ

Aldie Mansionの事例を基準にした歴史的レンガ会場を、固有名を強制しない架空会場「レンガのおやしき」として再構成する。現実の業務を保ちつつ、ゲームの地理は一目で理解できるよう三つの場所へ分ける。

1. **花屋の作業場**：入荷、洗浄、水揚げ、仕分け、制作
2. **搬入口・中庭**：搬入、円形アーチ、壺、噴水、アイル
3. **披露宴室**：長卓、スイートハートテーブル、式後の再配置

一日の時間が、朝の青い光→午前の中庭→午後の挙式→夕方の披露宴→夜の撤去へ進む。

## 6. 全14章

### 第0章：ふたりの希望を聞く

**目的**：仕事は「好きに飾る」前に、場所と希望を聞くところから始まると示す。

- A：色、会場、卓数、アーチ、再利用の希望を確認
- B：新郎新婦が三枚の大きな写真カードを指す。文字不要
- C：色布、花見本、会場写真をドラッグして一枚の設計ボードへ貼る
- 手応え：カードは紙の摩擦で少し遅れ、貼ると平らになる
- 自動化：予算・契約など成人向け要素は親モードの資料として表示

### 第1章：会場を測る

**目的**：花より先に空間を測る。

- A：扉幅、アーチ位置、人物の立ち位置、噴水周囲、卓幅を確認
- B：測る場所が一度だけ黄色い布タグで揺れる。ネオン輪郭は使わない
- C：大きな巻尺の端を片側からもう片側へ引く
- 補助：指が終点から少し外れても、30〜45 cm相当の磁石範囲で吸着
- 因果：狭い寸法を選ぶと大型モジュールが扉を通らない模型を短く見せ、分割設計へ直す

### 第2章：花が届く

**目的**：切花は個体差がある材料だと理解する。

- A：箱、保護紙、結束、品種札、折れ、開花差を描く
- B：良い花はゆっくり顔を上げ、傷んだ花は一枚だけ茶色い花弁がある
- C：紙をめくる、束を持ち上げる、バケツへ分ける
- 補助：束の当たり判定は見た目の1.8倍
- 間違い：別バケツへ置いても跳ね返さず、札が優しく近くへ移動して再選択を促す

### 第3章：バケツを洗って水を作る

**目的**：花の前に容器と水を清潔にする。

- A：残った葉、ぬめり、濁りを除き、指定量の水と切花栄養剤を混ぜる
- B：汚れは用途のある位置にのみ付く。こすると消え、水面の透明度が上がる
- C：スポンジで円を描く、レバーを倒して注ぐ、小袋を傾ける、棒で一周混ぜる
- 触感：水の慣性を少し誇張し、指を止めても一拍だけ回る
- 成功：泡が過剰に光らず、清潔な金属／樹脂の反射へ戻る

### 第4章：葉を取り、茎を切り戻す

**目的**：水面下の葉と新しい切断面の意味を体験する。

- A：水に入る部分の葉を除き、清潔な刃で茎端を切る
- B：予定水位を半透明の水面板で一時表示。取る葉だけが自然に揺れる
- C：葉を下向きになぞって外す。安全ハンドルを一回押して切る
- 感度：葉は3〜5 mm相当の短いなぞりでも外れ、茎は刃位置へ自動整列
- 因果：葉を残した比較バケツは時間経過の短い模型で水が濁る。恐怖や失敗画面は出さない

### 第5章：花を水へ入れて休ませる

**目的**：水揚げを「待ち時間」ではなく変化として見せる。

- A：茎端をすぐ水へ入れ、直射と熱源を避ける
- B：吸水を茎の内部に一時的な淡い流れとして見せるが、外縁発光はしない
- C：束を両手で持つ代わりに、一本指で重心ハンドルをドラッグし、水へ沈める
- 変化：花首が少し持ち上がり、花弁の張りが戻る。実時間は15〜25秒に圧縮
- 誇張：水を吸う音と、茎の内部の小さな気泡を強調

### 第6章：レシピごとに仕分ける

**目的**：色だけでなく、役割と茎長で分ける。

- A：主花、副花、線花、小花、葉、下垂材へ分類
- B：床に花の実物大シルエットではなく、用途を示す器型トレーを置く
- C：束を掴み、トレーへ落とす。近い役割なら補助スタッフが一言の音で直す
- 因果：長いデルフィニウムを低い卓上へ入れると視線を遮る模型を見せ、アーチ用へ戻す

### 第7章：低い卓上花を作る

**目的**：器、水、支持体、茎長、視線を一体で扱う。

- A：浅い器に金網を固定し、葉→主花→副花→線の順で組む
- B：差せる範囲を金網穴の物理的なくぼみと影で示す
- C：金網を押し込む、テープをなぞって固定、茎を差す、器を回す
- 感度：見た目より広い円錐状の挿入捕捉域。指を離すと最も近い妥当角へ5〜12度だけ補正
- 完成検査：向こう側の人形の顔が見える高さか、目線カメラで一回確認

### 第8章：アーチの土台を組む

**目的**：花より先に倒れない理由を作る。

- A：床パッド、ベースプレート、円形輪、重り、金網、水源、結束の順
- B：部品は実物比を保ち、把持用の仮ハンドルだけ大きくする
- C：脚を穴へ落とす、重りを押して滑らせる、金網を輪へ巻く、太い結束を引く
- 重量感：重りは指より遅れて動き、止めるとわずかに沈む。軽い花と明確に差別化
- 安全：刃物や鋭い金網端はスタッフが自動処理。プレイヤーは安全な端だけを扱う
- 検査：アーチを軽く揺らし、重り不足なら脚が少し浮く。追加後に安定する

### 第9章：アーチと噴水に花を入れる

**目的**：構造へ花を段階的に載せる。

- A：硬い枝葉で骨格→主花→副花→繊細花→仕上げ葉。重い花は支点近く
- B：次に必要な花束が作業台の手前へ自然に転がる。空中矢印は最小限
- C：枝を差す、葉を巻く、花を水管へ入れる、噴水の曲線へ沿わせる
- 感度：茎先だけでなく束全体を掴める。隠れた金網穴へ自動で深さを合わせる
- 因果：外側へ重い花を置くとアーチがわずかに傾き、支点近くへ戻すと安定
- 4歳向け短縮：代表8〜12本を触ると、同じレシピをスタッフが低速で続ける

### 第10章：箱へ入れ、車へ積む

**目的**：完成した花は壊れやすく、水を含む重い荷物である。

- A：設置順と逆の積込、バケツの転倒防止、花同士の間隔、ベルト固定
- B：車内を切断模型にして、床と棚を見やすくする
- C：箱を台車へ、台車をリフトへ、ベルトを横へ引く
- 重量差：重り箱、空箱、花バケツで慣性と音が違う
- 雨天分岐：防水カバーを広げ、濡れた床で台車を早く押すと停止距離が伸びる

### 第11章：会場へ設置する

**目的**：完成品を置くだけでなく、現場で仕上げる。

- A：養生→構造→大型装花→卓上→個人花→清掃→検査
- B：会場を近景・中景・遠景で明確にし、次の作業場所はスタッフの視線と台車の向きで示す
- C：台車を押す、モジュールを台へ落とす、花を数本追加、器の正面を回す、水を足す
- 感度：通路から少し外れても台車は壁へ衝突せず、自然なステア補助で中央へ戻る
- 制約：非常口、噴水の水路、車椅子通路を塞ぐと、床の人流が迂回して問題を可視化

### 第12章：会場を一周して直す

**目的**：「完成」は検査を含む。

- A：正面、横、裏、人物目線、卓上目線、火気、床、工具、しおれを確認
- B：虫眼鏡ではなく、子どもの身長のカメラで歩く
- C：画面をゆっくりなぞり、見つけた葉、結束端、水滴、傾きを触って直す
- 誤り例：左右対称の間違い探しにはしない。機能上の理由がある箇所だけを修正
- 完成演出：スタッフが片づき、ゲストが遠景から入る。過剰な紙吹雪やネオンは使わない

### 第13章：式の花を披露宴へ移す

**目的**：一つの装花が一日の途中で役割を変える。

- A：式終了後、決めたモジュールだけを外し、台車で披露宴へ運び、向きを編集
- B：移動前と移動後を、会場模型上の一本の色布ルートで示す
- C：留め具を外す、二人運搬ハンドルを引く、台車を押す、卓端へ回転して置く
- 因果：正面用の花をそのまま置くと裏の構造が見える。90度回し、葉を数本補うと完成
- 達成感：挙式写真と披露宴写真が並び、「同じ花が働いた」と分かる

### 第14章：片づけ、分け、記録する

**目的**：完成後も仕事が続き、部材が次回へ戻る。

- A：火気、花、器、水、構造、重り、床清掃、数量記録の順
- B：持ち帰り、寄贈、堆肥、再利用部材の4つの明確な行先
- C：花を束ねる、水を排水口へ運ぶ、結束を外す、部材を洗う、棚へ戻す
- 感度：小さな結束片は指の近くへ吸い寄せ、取りこぼしを防ぐ
- 終了：空になった会場に、床の傷やごみがないことを見て一日を終える

## 7. タッチ設計の数値方針

端末と実装エンジンで調整するが、初期値として次を採用する。

| 項目 | 初期値 | 理由 |
|---|---:|---|
| 主要ボタン最小タッチ領域 | 64 pt | 4歳児の狙い誤差を許容 |
| 3D物体の不可視ヒット領域 | 見た目の1.6〜2.2倍 | 茎や結束など細物を掴める |
| スワイプ成立距離 | 36〜44 pt | 短い腕移動で成立 |
| ドラッグ開始デッドゾーン | 4〜6 pt | 震えを無視しつつ反応を遅らせない |
| 挿入スナップ距離 | 対象直径の0.8〜1.5倍 | 穴へ正確に合わせなくてよい |
| 角度自動補正 | 最大5〜12° | 意図を保ち、勝手に回り過ぎない |
| 長押し必須時間 | 原則0 ms | 長押しを主要操作にしない |
| 二本指操作 | 0 | 片手で完結 |
| 誤操作後の復帰 | 1操作以内 | 罰や複雑なUndoを作らない |
| 一つの能動作業 | 20〜60秒 | 工程の意味を保ちつつ集中を切らさない |

### 見えない補助

- 指の下で物体が完全に隠れないよう、掴んだ物を8〜18 pt上へ持ち上げる
- 奥行き移動は画面縦位置と床面投影を自動変換
- 物体が別物の後ろへ隠れると、カメラが最大5°だけ回避
- 近い正解候補が複数ある場合、直前の動きの方向を優先
- 指を離す前に正解を奪わず、離した瞬間だけ最小限のスナップを行う

## 8. 触った感覚の作り分け

| 対象 | 指への追従 | 視覚・音 | 物理的意味 |
|---|---|---|---|
| 花・葉 | 軽いが茎根元に少し遅れ | 花弁の擦れ、茎の微小な曲がり | 柔らかい生体材料 |
| 水入りバケツ | 加速・停止が遅い | 水面の遅れ、低い揺れ音 | 液体を含む重量 |
| 金属輪 | 硬く、ほぼ変形しない | 接触音、冷たい粗い反射 | 荷重を受ける構造 |
| 重り | 指より遅い、床摩擦が大きい | 低い擦過音、床への沈み | 転倒防止 |
| 布 | 指に少し遅れてたわむ | 織り目、空気で揺れる | 装飾だが荷重は支えない |
| 結束 | 引くと段階的に締まる | 小さなクリック | 構造を固定する |
| 台車 | 積載量で慣性が変わる | 車輪継ぎ目音 | 搬入作業 |

## 9. 視覚方針

### 深度

- 近景：道具、手、花弁、器縁。高い材質解像度と接触影
- 中景：現在作る装花。最も明確な輪郭と主光
- 遠景：会場、スタッフ、次工程。低コントラストと空気遠近

### 材質

- 花弁：薄く、表裏差と透過感。ただし蝋やプラスチックの均一光沢にしない
- 葉：葉脈方向に粗さ差。すべて同じ緑にしない
- 茎：節、太さ、曲がり、切断面
- 金属：用途に応じた塗装、擦れ、結束跡。縁を発光させない
- 石：角の欠け、吸水による色差、目地。丸め過ぎない
- レンガ：目地深さ、焼成色差、局所的な汚れ。左右対称にしない
- 木：木目方向、端面、脚の接地、実用上の傷
- 水：反射だけでなく水位、慣性、容器壁との接触

### 汚れ・摩耗

汚れは「雰囲気を出すため」ではなく、発生理由から置く。

- バケツ内側の水位跡
- 台車車輪の泥と床の濡れ
- アーチ脚のボルト周囲の擦れ
- 作業台の刃物跡と水滴
- 石噴水の水が触れる位置の色差
- 搬入口の壁角だけの擦過

## 10. UIと説明

- 本編中の文字は保護者向け補助。4歳児には声、物の動き、スタッフの視線で伝える
- 画面上の常設UIは「戻る」「一時停止」「もう一度見る」の三つ以下
- 点滅する矢印を常用しない
- 正解物を発光縁取りしない。自然な影、揺れ、手本の一回動作で示す
- 失敗音、赤い×、星の減点、時間切れを使わない
- 危険な刃物や高所作業は、成人スタッフとの協働として描く
- 課金、広告、無限スクロール、ランダム報酬を置かない

## 11. 自動再生と能動操作の配分

全工程を網羅するが、全本数を触らせない。

- **能動操作**：原理が変わる最初の3〜12回
- **協働自動再生**：同じ操作の反復、スタッフがゆっくり続ける
- **再介入**：工程の節目で、重心、向き、水、搬入など別の判断をプレイヤーへ返す

例：アーチに120本を使うとしても、プレイヤーは硬い枝2本、葉3本、主花3本、線花2本、仕上げ葉2本を入れる。残りは、プレイヤーが作った方向性に沿ってスタッフが埋める。これにより工程を省略せず、操作だけを圧縮できる。

## 13. A・B・Cの受入基準

### A：現実性

- すべての大型装花に、床まで連続する荷重経路が見つかる
- 水が必要な花に水源または許容される短時間条件がある
- 器、卓、扉、人物、台車の寸法比が一貫する
- 搬入できない完成物を瞬間移動させない
- 正面以外からも、構造・接地・裏面が破綻しない
- 会場の通路、火気、床、水設備と両立する

### B：4歳児の理解

- 初見の4歳児の80%以上が、音声説明なしで最初の正しい操作を10秒以内に始める
- 1工程で必要な操作種類は原則1〜2種類
- 重要な原因と結果を、操作後3秒以内に見せる
- 読字を必要としない
- 失敗後、成人の介助なしで1操作以内に復帰できる

### C：製造感

- 指を動かしている間、対象が連続的に応答し、離した後だけ自動補正する
- 水、花、金属、重り、布、台車の追従と音が明確に異なる
- プレイヤーが作った位置・順番・方向が完成形に残る
- 自動再生はプレイヤーの仕事を置き換えず、反復だけを引き受ける
- 「作る前」「制作中」「完成」の状態差が、同じカメラ位置でも読める

## 14. 実装順序

### MVP 1：花店の作業場

第2〜7章を先に実装。水、葉、切断、吸水、仕分け、低い卓上花に集中し、触感の基礎を確立する。

### MVP 2：アーチ構造

第8〜9章。重り、輪、金網、水源、枝、花の荷重順を実装する。ユーザーの写実性要求に最も直結する。

### MVP 3：搬入と会場

第10〜12章。台車、雨、扉、床、設置、視線検査を実装する。

### MVP 4：一日の連続性

第0〜1章と第13〜14章を接続し、相談から撤去までを一つの時間軸にする。

## 15. トップページとの接続

現試作の14案は、単なるスキン選択ではない。本編のどの価値を最初に約束するかを比較するための入口である。

- 「朝の中庭」：完成への憧れを先に見せる
- 「花屋さんの朝」：仕事の始まりを見せる
- 「雨の日の搬入」：物流と重量を見せる
- 「花のうらがわ」：構造の真実を見せる
- 「会場をひと目で」：一日の工程全体を見せる

本採用候補は、写実性と固有作業を最も明確に予告する **13「花のうらがわ」**。子どもへの第一印象を柔らかくする場合は、13の構造を保ったまま、01「朝の中庭」の光と花の完成状態を重ねるハイブリッドを推奨する。
