# トップページ比較案の採用記録

初期試作では、光源・カメラ・写実度・材質・空間構成を大きく変えた15案を比較した。
本編では、ユーザー指定により案08 **「百二十四の層」** を正式採用した。

## 採用理由

- 木地、布、一辺地、二辺地、三辺地、中塗、上塗、金という、完成後には見えない構造をゲームの主題にできる。
- 「何度も塗り、待ち、研ぐ」理由を、説明文だけでなく断面の変化として示せる。
- 写実的な通常表示と、4歳児に読みやすい教育的な分解表示を切り替えられる。
- 全工程を通じて同じ椀が育つため、工程の連続性と製造感を保てる。

## 本編での継承

採用案の断面表示は、次の場所へ統合した。

1. ホーム画面の主役
2. 工程帳の「断面をみる」
3. 一辺地・二辺地・三辺地の層追加
4. 中塗・上塗後の層確認
5. 完成時の木地から金までの総覧

通常の作業画面では実寸比に近い厚みへ戻し、断面説明中だけ層間を離して読みやすくする。発光輪郭や根拠のないネオンではなく、材質、照明、陰影、物理的な分離で層を区別する。
