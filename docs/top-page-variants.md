# トップページ15案

色替えではなく、**主役、カメラ、光源、材質、空間、写実度、UI配置**を意図的に分離した比較実装である。全案とも写真背景ではなく、WebGL 2の実ジオメトリで構成する。

## 総当たり軸

- 写実度: 写実、工学模型、水墨、木版、箱庭、図面
- 主題: 完成椀、刷毛、布、地の粉、沈金、蒔絵、湿潤硬化
- UI: 左組、右組、下組、中央、技術図面

## 採用仮説

ユーザーの視覚嗜好と、本編への正しい期待の両方を考えると、次の順で有力。

1. **01 朝の塗師蔵** — 現実の工房、材質、近中遠景が最も素直。
2. **05 沈金・一条の光** — 輪島塗固有の因果が一瞬で伝わる。
3. **08 百二十四の層** — 工程ゲームであることが明確。
4. **15 夜の塗師風呂** — 省略されがちな硬化環境を主役にできる。
5. **03 炉端の朱** — 朱の正面大写しは強い。ただし炉を硬化装置と誤認させない。

比較時は「好きか」だけでなく、次の3問で評価する。

- 何を作るゲームか、3秒で分かるか。
- 触りたくなる対象が一つに絞れているか。
- 本編の現実的な工程表現を約束する画面か。

## 共通操作

- `?v=01`〜`?v=15` で直リンク
- 「案をくらべる」で一覧
- 左右ボタン／左右キーで切替
- 画面をなぞるとカメラを見回せる
- 軽いタップまたは「つくりはじめる」で6.8秒の工程予告
- iPhone / iPadの縦横でコピー、CTA、カメラ占有率を再配置
