# 「百二十四の層」本編実装仕様

## 1. 実装の中心

採用案08の価値は、完成面の美しさだけでなく、完成後には見えなくなる木地・布・下地・漆の関係を、空間として一目で理解できることにある。本編では断面を単なるトップページ演出で終わらせず、次の三箇所へ通した。

1. ホーム画面：8層を離して見せ、ゲーム全体の約束を提示する。
2. 第8章：一辺地、二辺地、三辺地が別の粒と厚みを持つことを操作で体験する。
3. 工程帳：いつでも完成器の内部を開き、既に作った層を確認できる。

通常の作業画面では各層を実寸比に近い重なりへ戻す。断面を常時厚くしたままにしないことで、説明用誇張と現実の器を分けている。

## 2. ソフトウェア構造

### `main.js`

ゲーム状態の唯一の進行管理者である。章、手順、完了状態、木材、加飾方法、音、保存を管理する。UIと3D世界を直接結び付けず、`TaskEngine`からの完了通知を介して進める。

### `game-data.js`

15章、41操作、32工程状態をデータとして定義する。各章は次を持つ。

- 表示名と工程群
- 3Dシーン種別
- 子どもが触る手順
- 自動工程の三つの説明拍
- 章完了時の言葉
- 工程帳へ記録する状態番号

この構造により、工程の順序をコードの分岐へ埋め込まず、資料との照合作業を行いやすくした。

### `tasks.js`

入力を14種類の操作文法へ正規化する。

- choice
- tap-target
- tap-repeat
- tap-spots
- swipe-x
- swipe-y
- swipe-free
- circle
- trace
- drag
- radial
- long-stroke
- dial
- sprinkle
- rotate

入力座標は物理的な指移動より約1.45倍大きく動かす。判定は広くするが、子どもの軌跡そのものは3Dへ渡す。したがって、補助によって勝手に完成するのではなく、「大きく受け止められた自分の動き」が残る。

### `workshop.js`

共通工房と15種類の工程シーンを構築する。シーンの切替時には動的ノードだけを破棄し、床、壁、障子、棚、作業台、遠景の椀などは保持する。これにより、すべての工程が同じ現実空間の中で進んでいる感覚を保つ。

各手順の進行率は材質、道具位置、層の不透明度、器の回転、粉や削り屑へ変換される。章末の自動工程では、工具の退避、硬化による濡れの減少、器の回転、層の沈み、金粉の定着などをタイムラプス表示する。

### `renderer.js`

WebGL 2の小規模レンダラーである。次を実装する。

- 透視投影
- 最大4灯の平行光／点光源
- 半球状の環境光
- 距離フォグ
- 粗さ、金属度、クリア層、濡れの近似
- 透明材質と両面材質
- プロシージャルな木、布、粒体、紙、石、漆、金
- Retina解像度上限

木目は強い渦模様を避け、未塗装木材の色域に収まる細い方向性と細孔へ抑えた。漆は一様なプラスチックではなく、粗さ、刷毛方向、濡れ、クリア層を分離する。金は発光せず、金属度の高いリボン形状として光を返す。

### `geometry.js` と `scene-kit.js`

椀は旋盤断面から生成する。外面と内面を別メッシュにし、口縁、高台、高台輪を追加する。断面案は、同じ外形を少しずつ拡大した8枚の部分回転体と、切断端のリボンで構成する。

加飾線は球の連続ではなく、椀の曲率へ追従する連続リボンで作る。これにより、ビーズ状の人工的な線を避け、沈金の溝または蒔絵線として読める幅へした。

### `ui.js`

HUD、工程指示、進捗、選択、工程帳、断面表示、完成画面を管理する。3Dと重なるUIは、作業対象の中央を避け、横画面では下中央、縦画面では安全領域内の下部へ置く。

### `audio.js`

WebAudioで、タップ、刷毛、研ぎ、注ぎ、金、章完了、完成の短い音を合成する。音源ファイルを読み込まないため、初回ネットワーク依存がない。音はユーザー操作後に開始する。

## 3. 描画空間

### 近景

工具、粉、紙、布、器の口縁、作業台の縁。高いコントラストと細かな材質差を持つ。

### 中景

主役の器と現在の工程。カメラの焦点をここへ置き、指の軌跡を残す。

### 遠景

障子、壁、棚、保管中の椀、塗師風呂。主役より彩度と光量を抑え、フォグで距離を分ける。背景ボケで隠すのではなく、シルエット、遮蔽、光量、空気遠近で奥行きを作る。

## 4. 章末自動工程

子どもが直接触らない工程を「省略」せず、短い自動再生へ回す。各自動工程は三つの説明拍を持つ。例として、第8章は次の順で進む。

1. 一辺地を硬化させ、軽く研ぐ。
2. 二辺地を硬化させ、再び研ぐ。
3. 三辺地を硬化させ、上塗へつながる面へ戻す。

同時に、3D上では工具が作業面から退避し、各層が硬化してわずかに締まり、濡れた見え方が落ち着く。

## 5. 幼児向け入力値

| 項目 | 実装値 |
|---|---:|
| 指移動の増幅 | 1.45倍 |
| 無入力から手本 | 2.4秒 |
| 線なぞり吸着 | 22% |
| 横／縦スワイプの方向許容 | 副軸が主軸の約45%未満 |
| 追跡線の判定半径 | 横12%、縦15%相当 |
| 大きなドラッグの置き半径 | 画面短辺の約23〜28%相当 |
| タップ対象半径 | 横20%、縦25%相当 |
| 誤操作時 | 進捗を減らさない |

端末の物理寸法は機種で異なるため、最終値は実機で4歳児の指の移動、離指位置、誤タップを記録して調整する。

## 6. 状態保存

保存キーは `wajima-124-layers-save-v2`。保存データへバージョンを持たせ、将来の工程追加で旧形式を誤読しないようにする。保存に失敗してもゲームを停止させず、プライベートブラウズ等ではセッション内で遊べる。

## 7. PWA

Service WorkerはHTML、CSS、WebGLコード、ゲームデータ、アイコンを事前キャッシュする。外部CDNを使わないため、初回キャッシュ後はネットワークなしで本編を開始できる。Service WorkerはHTTPS、localhost、127.0.0.1でのみ登録する。

## 8. 次の精密化で測るもの

- iPhone 17と複数世代iPadでの平均／1% low FPS
- 4歳児が各操作を完了するまでの時間
- 手本表示まで待った割合
- ドラッグの離指位置分布
- 上塗の長ストロークが途中で切れる割合
- 縦画面と横画面の選択率
- 沈金と蒔絵を視覚的に区別できた割合
