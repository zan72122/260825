# 実装検証記録

検証対象：4歳児向け3Dモバイルゲーム「百二十四の層」本編

## 1. 静的検査

実行コマンド：

```bash
npm run check
npm test
```

結果：

- `src/*.js` と `sw.js` のJavaScript構文検査に合格
- 15章が存在
- 章IDに重複なし
- 41のインタラクティブ手順が存在
- 32の工程状態が存在
- 全章に章末自動工程が存在
- 全章の自動工程に三つの説明拍が存在

## 2. 3Dシーン・状態検査

Node上のスモークテストで、全41手順について次を実行した。

1. 工程シーンを構築
2. 進捗0.5を適用
3. 指の軌跡に相当する3Dストロークを追加
4. 進捗1.0を適用
5. 各章の最終手順では自動工程0.5と1.0を適用
6. 世界更新を1フレーム実行
7. 可視メッシュ数を確認

全手順で例外なし。すべてのシーンに十分な実ジオメトリが生成された。

結果：

| WebGLエラー | 0 |

代表画面として、ホーム、塗師風呂、沈金、蒔絵、検品、完成、縦画面ホーム、縦画面三辺地を目視確認した。

## 4. 章進行検査

結果：

## 6. オフライン構成

- 外部JavaScriptなし
- 外部画像なし
- 外部フォントなし
- `manifest.webmanifest` あり
- 192px／512pxアイコンあり
- Service Workerの構文検査に合格
- HTML、CSS、全JavaScript、アイコンをプリキャッシュ対象に登録

Service Workerの実動作にはHTTPSまたはlocalhostが必要である。

## 7. 修正した問題

検証中に次を修正した。

- ろくろ回転が配列の添字ではなく未使用プロパティへ書かれていた問題
- 箱入れ時に加飾線の座標系が器とずれる問題
- 加飾線が球の連続でビーズ状に見える問題
- 完成画面で加飾線が器の内側へ沈む問題
- 木目のコントラストが強く、人工的な大渦に見える問題
- 完成タイトルが不自然な一文字改行になる問題
- 章末自動工程が文字の進捗だけで、3D上の硬化・回転・退避を伴わない問題
