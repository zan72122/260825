# ウェディング会場装花（フラワーアレンジメント）調査

- 調査日：2026年8月25日
- 対象：会場装花のうち、生花・枝葉を用いたフラワーアレンジメント
- 基準事例：**Aldie Mansion（Doylestown, Pennsylvania）での実婚礼**
- 装花担当：**Hatfield Florist**
- ゲーム化対象：相談、設計、仕入れ、下処理、制作、梱包、搬入、設営、完成確認、式から披露宴への再配置、撤去

## 1. この事例を選んだ理由

会場装花の公開記事は、完成写真だけ、花材名だけ、あるいは一般的な相談手順だけに終わるものが多い。本事例は、同一の婚礼について次の情報を一つの花店が公開している。

1. 実在会場と担当花店が特定できる。
2. 電話相談と現地でのサンプル確認が行われたことが分かる。
3. 挙式会場の円形アーチ、壺、噴水基部、歓迎コーナーの設置場所が分かる。
4. バラ、ラナンキュラス、トルコキキョウ、デルフィニウム、ストック、ユーカリなど、主要花材が分かる。
5. 挙式装花を披露宴へ移して再利用したことが分かる。
6. 披露宴の長卓とスイートハートテーブルまで同じ色・形の設計が連続している。

このため、「完成した花の写真を真似るゲーム」ではなく、「一日の仕事として会場を花で組み立てるゲーム」の基準にしやすい。

## 2. 情報の確度区分

本書では、情報を混ぜないため三段階に分ける。

| 区分 | 意味 | 本書での扱い |
|---|---|---|
| **事例確認済み** | Aldie Mansionの当該婚礼について公開記事で確認できる | 花材、色、設置場所、相談、現地確認、再配置など |
| **会場確認済み** | 会場公式情報で確認できる | レンガ、鉛入り窓、石テラス、噴水、庭、屋内外スペースなど |
| **業界資料からの再構成** | 当該婚礼の内部記録はないが、実務資料で一般的工程・構造を確認できる | 水揚げ、アーチの重り・金網・水源、当日の時間配分など |

特に、**当該円形アーチの内部構造、正確な寸法、使用本数、車両、スタッフ人数、搬入時刻は公開されていない**。ゲームでこれらを描く場合は、実例そのものの事実ではなく、別の実務資料から作った妥当な設計仮説として表示する。

## 3. 会場：Aldie Mansion

Aldie Mansionは、Tudor様式を特徴とする歴史的会場で、複雑なレンガ積み、鉛入り窓、彫刻、広い石テラス、噴水、庭園を持つ。屋内にはGreat Hall、Library、Garden Room、Ballroom、Mercer Dining Roomがあり、屋外にはFront Courtyard、Patio、Back Lawn、Tea Gardenなどがある。会場公式情報では最大220名、約120台分の駐車、ADA対応が案内されている。

### 装花設計に効く会場条件

- **レンガ壁**：赤褐色で情報量が多いため、淡い花色でも輪郭が消えにくい。反対に、赤・橙を大量に使うと壁と同化する可能性がある。
- **鉛入り窓**：細かな格子が背景に入る。アーチは窓格子と競合しない太さと抜けが必要。
- **石テラスと噴水**：重く硬い水平面に対し、枝葉と垂れる花で動きを足せる。
- **中庭**：壁に囲われるが屋外であり、風、雨、直射、温度、搬入口からの距離を考える必要がある。
- **屋内外の連続**：挙式から披露宴へ同じ装花を移す運用が成立しやすい一方、扉幅、段差、通路、ゲスト動線を先に測る必要がある。

## 4. 当該婚礼で確認できる装花

### 4.1 全体コンセプト

- 色：ブラッシュピンク、クリーム、白、少量のダスティーブルー
- 葉：流れるグリーン、ユーカリ系の銀緑
- 形：密な球体ではなく、花の塊と抜け、下垂する葉を組み合わせた庭園的構成
- 会場との関係：歴史的レンガと既存庭園を覆い隠さず、花で焦点を作る
- 空間連続：挙式の柔らかな春色を、披露宴の長卓と高砂まで繰り返す

### 4.2 場所別の装花台帳

| 設置場所 | 事例確認済みの内容 | 機能・見え方 | ゲームで保持すべき現実性 |
|---|---|---|---|
| 歓迎コーナー | 紙のパラソル／扇子を入れた編み籠、ブラッシュと白の花 | 会場入口で色と用途を予告 | 籠は床に接地し、花は通路を塞がない |
| 中庭の円形アーチ | アイボリー布、バラ、ラナンキュラス、トルコキキョウ、流れるグリーン | 誓いの視覚的焦点、人物を囲むフレーム | 花の重さを支える輪・脚・重り・結束が必要 |
| クラシックな壺 | 声明性のある大きなアレンジ | アーチ以外の垂直焦点、左右や入口の補助 | 器の容量・重心・転倒防止・水源が必要 |
| 中庭の噴水基部 | 花とグリーンが下へ流れる設置 | 石の円形に沿って動きと柔らかさを加える | 水の流路、歩行域、滑り、設備への固定禁止を確認 |
| 花嫁ブーケ | アイボリー／ブラッシュのバラ、白ラナンキュラス、トルコキキョウ、ストック、ユーカリ | 最も近くで撮影される個人花 | 握れる太さ、茎の揃え、重量、手元の水切れを考慮 |
| ブライズメイドブーケ | 同系色にパステルピンク、柔らかな青を追加 | 衣装との色連携、花嫁との階層差 | 花嫁より小さく、同一レシピの変奏にする |
| 披露宴の長卓 | 低いブラッシュ／アイボリーの花、バラ、ラナンキュラス、トルコキキョウ、デルフィニウム、銀緑ユーカリ、下垂葉 | ゲスト同士の視線を妨げず、卓上を連続させる | 食器・料理・蝋燭・手の到達範囲を侵さない |
| スイートハートテーブル | 下へ流れる花、ランタン、蝋燭 | 室内の焦点、挙式装花の物語を継続 | 布への接触、火気距離、器の転落、足元空間を確認 |

## 5. 実務工程の全体像

以下は、Hatfield Floristが公開する相談・提案・設置手順、当該事例、切花管理資料、他の婚礼花店の当日工程、アーチ構造資料を統合したもの。太字の「事例確認済み」以外の時刻は、当該婚礼の記録ではなく実務的な再構成である。

### Phase 0：問い合わせ・予約

**推奨時期：婚礼の9〜12か月前。詳細設計は3〜4か月前からでもよい。**

最初に集める情報：

- 婚礼日、会場、挙式と披露宴の場所
- ブーケ・卓上・壺・アーチなどの数量
- 色、雰囲気、参考画像
- ゲスト数、卓数、長卓か円卓か
- 予算の優先順位
- 会場への搬入可能時刻、撤去時刻、階段、扉、駐車
- 挙式装花を披露宴へ移すか

**当該事例では電話相談と、現地でサンプルを見る打合せが行われた。**

### Phase 1：現地確認・採寸

最低限、次を測る。

- アーチ位置の床幅、天井／樹木高さ、人物が立つ範囲
- 構造物の脚を置ける場所と重りを隠せる空間
- 扉幅、曲がり角、段差、エレベーター
- 噴水の直径・立上り・水の動き・立入禁止域
- 卓上の幅、食器・蝋燭・テーブル番号の占有域
- 写真の正面軸と、横から見える裏面
- 風、雨、日射、空調、火気、文化財保護の規則

写真は「正面の完成予想」だけでなく、脚、裏面、搬入路、コンセント、排水、床仕上げを撮る。

### Phase 2：デザイン・見積・レシピ

1. どこを最大の焦点にするか決める。
2. 個人花、挙式、披露宴の優先順位を決める。
3. 花材を、主花・副花・線・小花・葉・下垂材に分ける。
4. 各器／構造ごとに本数と予備を設定する。
5. 季節、入手性、天候、物流、設計難度を反映する。
6. 再配置できる単位に分割する。
7. 提案書に、設置場所、外形、色、器、数量、設営、撤去を記載する。
8. 予算に応じ、焦点へ高価な花を集中し、他は色と葉で面積を作る。

Hatfield Floristは、相談後に設計案、概算、推奨事項を含む個別提案を作り、修正・確定する流れを公開している。

### Phase 3：調達計画

当該事例の発注日は非公開。一般には、次を確定する。

- 品種だけでなく色域、花径、開花段階、茎長
- 代替花の優先順位
- 暑さ・風・水切れへの耐性
- アーチ用の硬い枝葉と、繊細花用の個別水源
- 器、バケツ、台車、梯子、養生、工具、重り、金網、結束、予備部材
- 再配置時に持てるモジュール重量

ラナンキュラスのように開花調整が必要な花は、気温と到着日の余裕を持つ。輸送遅延や品質不良の代替も準備する。

### Phase 4：入荷・検品・コンディショニング

婚礼の2〜3日前を基準とする再構成。

1. バケツと器を洗い、植物残渣を残さない。
2. 花を箱から解き、品種・色・本数・折れ・褐変・病斑を確認する。
3. 水面下に入る葉・棘・脇芽を除く。
4. 清潔で鋭い刃物で茎端を切り戻す。
5. 指定量の水と市販の切花栄養剤を用意する。
6. 種類・茎長・用途別にバケツへ分ける。
7. 直射と熱源を避け、十分に吸水させる。
8. 開き過ぎ、開かなさ過ぎ、折れを再確認し、予備と交換する。

市販の切花栄養剤には、水を酸性側へ調整し、糖質を与え、細菌増殖を抑える目的がある。水中の葉を除き、清潔な刃物で切り戻すことは、単なる美観ではなく水質と吸水の管理である。

### Phase 5：工房での制作

婚礼前日〜当日朝を基準とする再構成。

- ブーケをレシピ本数で束ね、手で持った重量と正面を確認
- 小さな卓上花を器ごとに制作
- 壺や噴水用の移動可能なインサートを制作
- アーチの金網ケージや水源を、搬入可能な長さに分割して下組み
- ラベルを「挙式右」「噴水前」「長卓3」など設置位置で付ける
- 背の高い枝、繊細花、仕上げ花は現場挿しに残す
- 花同士が押し潰れない運搬箱、滑り止め、固定ベルトを用意

大型設置物を完成状態で運ぶと、扉を通らず、振動で花が傷み、重心が高くなる。したがって「構造」「葉の基礎」「花の仕上げ」を分ける。

### Phase 6：積込・搬入

一般的な婚礼では、規模とアクセスにより式の2〜5時間前に現場入りする例がある。

積込順は、現場で降ろす順の逆にする。

- 最初に設置するアーチ脚・重り・養生を最後に積み、最初に降ろす
- バケツは転倒防止枠へ固定
- 花を荷物の重りとして扱わない
- 濡れた路面では台車の停止距離を増やす
- 雨天時は花だけでなく床、段差、電源、布、段ボールを守る
- 会場担当者と、搬入口・設置完了時刻・一時保管場所を再確認

### Phase 7：現地設営

推奨順序：

1. 床・壁・噴水を養生する。
2. 人や車の動線を残して工具・バケツを配置する。
3. 挙式の主要構造を最優先で組む。
4. 脚、ベース、重り、輪、金網、水源を固定する。
5. 硬い枝・葉で大きなシルエットと荷重経路を作る。
6. 主花を焦点へ、次に副花・線・小花を入れる。
7. 最後に繊細花と下垂材を入れ、構造を必要な範囲だけ隠す。
8. 壺、噴水基部、歓迎コーナー、アイルを配置する。
9. 披露宴は卓上の幅と視線を測りながら置く。
10. 個人花を撮影開始時刻に合わせて引き渡す。

### Phase 8：完成確認

「花が多いか」ではなく、次の検査を行う。

#### 構造

- 手で軽く揺らしても脚が浮かない
- 重りが脚へ確実に結ばれている
- 金網・結束の切断端が人へ向かない
- 水を足した後の重量でも倒れない
- 裏側から見ても危険な突起がない

#### 花と水

- 水位が十分で、水中に葉がない
- 花首が折れていない
- しおれや褐変を予備花と交換
- 繊細花には水管などの水源がある
- 直射・暖房・炎の近くに弱い花を置かない

#### 会場・人物・写真

- 誓いの位置から顔を隠さない
- 車椅子、スタッフ、ゲストが通れる
- 卓上で向かいの顔が見える
- 蝋燭の炎と葉・布に距離がある
- 噴水の水路や非常口を塞がない
- 正面だけでなく斜め・横・裏から破綻しない
- 工具、切葉、結束片、水滴を回収する

### Phase 9：挙式から披露宴への再配置

**当該事例では、花店チームが式後まで残り、屋外の挙式花の一部を披露宴エリアへ移して再利用した。**

再配置を成立させる設計条件：

- 最初から「移す単位」を決める
- 器やインサートに持ち手／把持箇所を残す
- 水を含んだ実重量で、2人運搬か台車かを決める
- ゲストが移動中の通路と交差させない
- 披露宴側の受け皿、台、床養生を先に用意する
- 移動後に正面を変え、隠れていた構造を葉で補修する
- 再配置を価格、時間、スタッフ計画に含める

これは「同じ花を二度見せる」だけではない。挙式の正面用だった花を、披露宴では横長の卓や入口用へ向きを変える編集作業である。

### Phase 10：撤去・回収・終了

当該事例の撤去方法は非公開。一般的には次を行う。

1. 火気を消し、ゲスト動線と分けて作業する。
2. 持ち帰り花、寄贈花、廃棄花を分ける。
3. 繊細な花、水入り容器、重い構造の順を考えて解体する。
4. レンタル器、輪、ベース、重り、金網、水管を回収する。
5. 結束材、ワイヤー片、花粉、水、葉を床から除く。
6. 会場設備に傷・濡れ・詰まりがないか確認する。
7. 再利用部材を洗浄・乾燥・数量確認する。
8. 植物残渣を、地域の条件に応じて堆肥化／適切に処分する。
9. 使用本数、破損、代替、所要時間を記録し、次のレシピへ反映する。

## 6. 大型アーチの内部構造：公開情報からの妥当な再構成

### 重要な限界

Aldie Mansionの当該円形アーチ内部は公開されていない。以下は、別の実際の婚礼アーチ制作例から導く**構造候補**である。

実務例では、約5 ft幅×8 ft高の鉄製アーチが、花を付けると約7 ft幅×9 ft高になり、脚を重りで固定し、幅12 inの被覆金網、片側6個の水入り容器、結束バンドを使った。別資料でも、金網を筒状にして構造へ結束し、枝を先に入れて骨格を作り、葉をワイヤー／結束で固定し、花には水管を付ける手順が公開されている。

ゲームのアーチは、これを一つの妥当なモデルとして次の順に構築する。

1. **床**：水平、摩擦、文化財保護用パッド
2. **ベースプレート**：脚荷重を床へ分散
3. **垂直脚／円形輪**：曲げとねじれを受ける金属構造
4. **重り**：前倒れ・横倒れを抑える。花を付ける前に設置
5. **金網ケージ**：茎を多方向から支える。切断端を内側へ処理
6. **水源**：水入り容器、水管、吸水保持材などを花の性質に合わせる
7. **硬い枝・葉**：花を受ける二次骨格とシルエット
8. **主花・副花・線花**：重い花を支点近く、軽い花を外縁へ
9. **仕上げ葉**：機構を隠すが、点検箇所まで完全に塞がない
10. **最終荷重検査**：水を含んだ状態、風、接触、裏面を確認

### ゲームで避ける嘘

- 花が輪の表面に磁石のように貼り付く
- 重い花房が細い茎一本だけで水平に浮く
- 脚や重りがなく、アーチが自立する
- 水源のない繊細花が長時間まったく変化しない
- 正面を花で隠しただけで、裏側に構造がない
- 解体時に金網や結束が消滅する

## 7. 本事例から作れる「会場装花の本質」

1. **花を作る前に、場所と動線を設計する。**
2. **切花は材料であると同時に、水を吸い続ける生体である。**
3. **大型装花は、彫刻ではなく荷重・水・搬入を持つ仮設構造物である。**
4. **完成形は正面写真だけではなく、ゲストの視線、食事、火気、通路と共存する。**
5. **一日の途中で用途が変わる。** 挙式から披露宴へ移す設計は、最初からモジュール化する必要がある。
6. **美しさは最後の一層であり、その下に洗浄、採寸、重り、結束、ラベル、台車、清掃がある。**

この6点をゲームの中核にすることで、「花を自由に飾るだけの着せ替え」から、「本物の現場を子どもが理解できる仕事体験」へ変えられる。

## 8. 公開されていない情報

次の項目は、当該事例について確定できなかった。

- 婚礼日と季節の正確な記載
- 全花材の品種・産地・本数・単価
- アーチ、壺、噴水装花の正確な寸法
- 円形アーチのメーカー、脚、重り、金網、水源
- 作業員数と役割分担
- 入荷日、保管温度、制作時間
- 搬入車種、積載順、会場アクセス時刻
- 挙式後に移した具体的な全パーツと移動先
- 撤去時刻、廃棄・寄贈・持ち帰りの内訳

したがって、今後実装する本編では、これらを「Aldie実測値」と表示しない。一般的な業務シミュレーション値として、設定画面または資料欄に根拠区分を示す。
